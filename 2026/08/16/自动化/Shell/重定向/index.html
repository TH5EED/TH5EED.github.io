地基

每个进程启动时有三个默认“数据流”：
stdin 标准输入
stdout 标准输出
stderr 标准错误

重定向和管道的本质就是把某个数据流转接到别处

cat <<EOF ... EOF（不加文件名参数）就是在正常的读写中当一个搬运工，所以就是一个显示在屏幕上的工具，数据该写在哪该是写在哪

|管道是将左边命令的标准输出接到右边命令的标准输入中去

tee从标准输入中读，然后分叉写入标准输出和屏幕中去

cat << EOF … EOF

讲接下来的键盘输入（直到遇到EOF标记）传给cat

优于echo，用于打印大段信息

执行该脚本后

结合>快速写入配置文件（覆盖/追加）

不变的还是
cat << EOF
…
EOF
只不过中间有了> file.conf 或>> file.conf

EOF带引号防止内容转义

这样可以将里面的$ /等符号不当做变量展开

合并多个文件

cat a.txt b.txt > all.txt

清空文件（不删除）

cat /dev/null > huge.log
比rm快，且不影响正在写入的进程，用于清空日志

在终端上直接创建文件（不用EOF ）

输入 cat > 1.txt，然后ctrl+d结束
