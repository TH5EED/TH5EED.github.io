本质

API定义了“用户能说什么”，”用户能怎么说“，”会怎么回复用户“，屏蔽了复杂性
点菜，用户只需要看着菜单，说吃什么菜，吃米饭或馒头，放不放香菜等，不需要关注怎么做出来

三大要素

动词，methods

HTTP中常用增删改查GET/POST/PUT/DELETE
k8s中还有Watch监听，Proxy代理等

名词，resources

对”什么“操作，比如用户数据，图片文件，pod，service，deployment

格式，schema
