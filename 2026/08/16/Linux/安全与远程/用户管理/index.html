用户管理

发表于2026-08-16|更新于2026-08-16|Linux
|浏览量:

用户管理文件/etc/passwd

root:x:0:0:Super User:/root:/bin/bash

  • 用户名称，只是方便管理员记忆
  • x为密码标记，表示有密码，真正存在于/etc/shadow中
  • UID，用户唯一标识，0为超级用户，可以多个超级用户；0~999为系统用户；后为普通用户
  • GID（初始组），创建用户后系统自动创建同名的初始组；用户可加入多个附加组
  • 用户说明
  • 家目录
  • 登录后执行的程序，常见/bin/bash,/usr/sbin/nologin等，如果执行自己编辑的一个脚本，执行后又会回到原用户，所以常见的执行程序是终端bash或sh

影子文件/etc/shadow

abc:!:20567:0:99999:7:::

  • 用户名称，同/etc/passwd
  • 加密密码，SHA512散列加密，可在前面加入!,*改变加密值；如果没有密码为!
  • 密码上次修改时间，时间戳（1970.1.1后每过一天加一）
  • 两次密码修改间隔时间
  • 密码有效期
  • 密码到期前警告天数，默认7
  • 密码过期后宽限天数
  • 账号失效时间
  • 保留

组信息文件/etc/group

abc:x:1000:

  • 组名，用户的初始组
  • 组密码，x代表标识，真正存在于/etc/gshadow中，用于指定组管理员
  • 组ID
  • 组中用户，除了同名用户，主要看有没有将本组作为附加组的用户

组密码文件/etc/gshadow

不要设置密码

模板文件/etc/skel

新建用户家目录出现的隐藏文件——系统变量文件，就是复制的模板文件

用户管理命令

useradd

useradd在添加用户时有两个参考的默认值文件/etc/default/useradd，/etc/login.defs

  • -u UID 指定UID，不要小于999
  • -d 指定家目录，绝对路径
  • -c commit /etc/passwd第五个字段
  • -g 指定初始组
  • -G 指定附加组
  • -s shell 指定登录shell，默认/bin/bash
  • -e erase 指定用户失效⽇期，格式为“YYYY-MM-DD” ，/etc/shadow第八个字段

gpasswd

将用户添加进组或删除出组

  • -a 用户加入组
  • -d 删除

usermod

usermod -aG wheel mini
将用户mini加入wheel为附加组，不然普通用户无法使用sudo

usermod -aG docker mini
不然无法使用docker命令
