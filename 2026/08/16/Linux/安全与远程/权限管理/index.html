权限命令

权限作用

  • 文件的写
    根据文件和上一级目录的block所存储的关系，拥有写权限并不能删除当前文件，除非拥有上一级目录的写权限

  • 目录的执行
    可以cd

普通用户设置目录权限只有0，5，7这三种可能

两种执行方式的区别

执行方式 文件需要 目录需要
./script.sh（直接执行） x 权限 所有父目录都要有 x
bash script.sh（解释器执行） r 权限 所有父目录都要有 x

为什么第二种只需要 r？
因为 bash script.sh 是让 bash 程序去读取这个文件内容并解释执行，而不是把文件当作二进制程序直接运行。但 bash 本身必须能进入该目录（所以父目录的 x 仍然需要）。

图示

chmod

421分别代表读写执权限
chmod xxx 目标文件

chown

修改文件或目录的所有者和所属组 root:root
==每创建一个用户，会自动创建一个同名的组==
==普通用户不能改所有者和所属组==

  • -R 递归修改，给子目录中所有文件设置权限
  • -h只将链接文件修改权限
  • -H将链接所指源文件有修改权限

chgrp

修改文件或目录的所属组

umask

指定默认权限值：文件644目录755
保证系统中不存在没有权限的文件或目录
