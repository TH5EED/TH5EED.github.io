系统监控常用命令

df

disk freesystem
显示系统中各文件系统的总空间、已用空间、可用空间和挂载点等信息

  • -Th
    • -T Type
    • -h human
  • -l local

du

disk used
显示目录或文件的磁盘使用情况

  • -sh
    • -h human
    • -s sum
  • -a all

iostat

每秒显示I/O统计

free

free memory
显示系统内存使用情况，包括物理内存和交换空间的使用统计

  • -h
  • -m 以MB为单位
  • -g GB

top

table of processes
实时查看系统资源和进程

  • -p PID

  • -u user

  • -d N 设置刷新间隔时间，默认5秒

  • -b 批处理，适合脚本

  • 1：显示/隐藏每个CPU核心的使用情况

  • P：按CPU使用率排序

  • M：按内存使用率排序

  • k：终止进程

  • r：调整进程优先级

  • q：退出top

htop

top加强版

ps

process status

ps -ef
everything format
所有进程+完整格式

ps aux
所有用户+用户导向+无终端进程

⚠️ 关键区别（面试高频）

  • -ef 有 PPID（父进程ID） → 查进程树/父子关系时用它
  • aux 有 %CPU / %MEM / VSZ / RSS → 查资源占用时用它

lscpu

显示CPU架构信息

查看系统

你的需求 推荐命令 预期结果示例
看硬件型号 (如 Dell, Lenovo) sudo dmidecode -s system-product-name ThinkSystem SR650
看系统架构 (如 Intel, ARM) uname -r 内核版本+x86_64 或 aarch64
看硬件配置摘要 sudo lshw -short 列出 CPU、内存、磁盘等概览
看 CPU 具体型号 cat /proc/cpuinfo Intel(R) Xeon(R)...
看Linux系统版本 cat /etc/os-release NAME="Rocky Linux"<br>VERSION="10.1 (Red Quartz)"<br>ID="rocky"<br>ID_LIKE="rhel centos fedora"<br>VERSION_ID="10.1"
