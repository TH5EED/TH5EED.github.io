📝 命令总结与速查表

为了方便你记忆，我把最常用的几个场景和命令整理如下：

你的需求 推荐命令 说明
查所有可安装的包 yum list available或yum list或yum list 包名 --showduplicates看所有版本 ✅ 唯一正确方法。rpm 做不到。
查本机已安装的包 yum list installed 或 rpm -qa 两者都可以，yum 的输出通常更直观。
查某个包的信息（版本、依赖等） yum info <包名> yum 会告诉你这个包在仓库里的状态（是否已安装）。
根据模糊名字找包 yum search <关键词> 比用 rpm -qa | grep 更强大，因为它会在仓库的所有包里搜索。
查本机某个文件属于哪个包 rpm -qf /path/to/file 这是 rpm 的经典用法，也很快速。

简单来说：想“逛商店”看能装什么，用 yum；想“查自家柜子”看装了什么，rpm 和 yum 都行。

📊 Linux 软件安装方式对比

为了帮你从根上理解，我把常见的几种安装方式做了个对比：

对比项 YUM 安装 (yum install) RPM 本地安装 (rpm -ivh) 官方二进制解压 (tar + 移动)
包管理器介入 有 (自动下载包、解析依赖、安装) 有 (仅安装指定的单个包，不处理依赖) 无 (纯手动)
处理依赖 ✅ 自动处理 ❌ 不处理，依赖缺了会报错 ❌ 完全不处理
文件来源 从网络仓库自动下载 已下载到本地的 .rpm 文件 从 GitHub 手动下载 .tar.gz
卸载/升级 yum remove/update 轻松管理 rpm -e 可管理，但需手动处理依赖 完全手动，删文件或替换文件
系统集成度 高 (注册到 RPM 数据库，可被 rpm -qa 查询) 高 (同样注册到 RPM 数据库) 无 (系统“不知道”有这个东西)
