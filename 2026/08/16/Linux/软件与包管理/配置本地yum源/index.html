本地yum源介绍

让yum包管理器不再尝试去连接那些无法到达的远程仓库，而是直接从本地挂载的ISO镜像文件获取软件包和依赖信息，从而在离线环境中也能顺利完成软件的安装和管理

操作步骤

  1. 用系统版本相近的镜像文件作本地yum仓库

  2. 创建挂载目录mkdir /mnt/cdrom

  3. 将镜像挂载到目录mount /path/to/CentOS-7-x86_64-DVD.iso /mnt/cdrom

  4. 备份原仓库，创建本地仓库
    mkdir /etc/yum.repos.d/bak && mv /etc/yum.repos.d/*.repo etc/yum.repos.d/bak/

  5. 创建并编辑文件vi /etc/yum.repos.d/local.repo

  1. 清理缓存yum clean all

  2. 生效yum makecache
