软件包介绍与命令

发表于2026-08-16|更新于2026-08-16|Linux
|浏览量:

源码包

优点

  1. 开源：可修改代码，安全，稳定
  2. 编译前（记得安装gcc）有配置选项，可自由选择所需选项对应的功能
  3. 本地化编译：根据当前CPU架构优化，编译出最适合的二进制，稳定，高效率
  4. 卸载方便（提前指定安装位置）

缺点

  1. 编译时间长
  2. 安装步骤多易出错
  3. 出错难解决

二进制包

DPKG

Debian开发的包管理机制
应用在Debian和Ubuntu系

RPM

Red Hat开发的包管理系统
红帽系

包名，系统中已安装的包
httpd

包全名，系统中未安装的包，注意要绝对路径或进入仓库内
httpd-2.4.63-4.el10.x86_64.rpm
版本号，发布次数4，发行商el10，硬件架构

优点

  1. 包管理系统简单：几个命令实现安装、升级、查询和卸载
  2. 安装速度快

缺点

  1. 经过了编译，看不到源代码
  2. 功能选择不如源码包安装
  3. 依赖性：包依赖，函数库依赖

特点

不用指定安装位置：

  • /etc/配置文件
  • /etc/bin可执行命令文件
  • /usr/lib所依赖函数库
  • /usr/share/man帮助文件
  • usr/share/doc使用手册

手工命令安装

优点

查询本机安装的rpm的相关信息

缺点

手工解决依赖性

命令选项

  • -ivh

    • -i install
    • -v verbose
    • -h hash打印进度

  • –force

  • –test 只测试依赖性不安装

  • -U 升级，也跟包全名不是包名

  • -e erase 擦除卸载

  • -q [包名]query查询本机

  • -qa 查询本机所有已安装

  • -qi [包名] information 查询某个已安装的包的详细信息

  • -qip [包全名] package 查询未安装的包的详细信息

  • -ql [包名]location查询包的安装的位置，不用管路径

  • -qlp [包全名] 查询未安装包的预安装位置

  • -qf [file] 查询系统文件属于哪个包

导入数字证书



两个位置无所谓，推荐导入虚拟光驱中的，因为只读
rpm --import /mnt/cdrom/RPM-GPG-KEY-Rocky-10
验证是否有gpg公钥
rpm -qa | grep gpg

yum在线安装

8版本后可升级为dnf安装

优点

官方会提供一个yum源，里面保存所有rpm包，通过命令连接yum源，自动下载依赖

缺点

查询yum源服务信息，不能查询本机rpm信息

yum源配置文件

/etc/yum.repos.d下的.repo文件，注意部分文件为模板文件并不起效

文件中各参数：

命令选项

  • install -y
  • remove -y

查询查的是yum源中的包，并非本机

  • provides 查询命令属于哪个包
  • search 同上

列出仓库中所有可供安装的软件包

  • list available
  • list

列出可更新的软件包

  • yum list updates
