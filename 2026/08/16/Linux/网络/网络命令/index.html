网络命令

发表于2026-08-16|更新于2026-08-16|Linux
|浏览量:

ip

  • a(dd(ress)) (sh(ow)) 显示IP地址（可简写）ip a
  • r(oute) ((sh)ow) 显示网关 ip r
  • 临时更换IP和网关，不建议

nmcli

NetworkManagerClient

ifconfig

看IP信息，nmcli更常用
也可以临时更换

ifup、ifdown

开关网卡
后跟网卡名即可

ping

通过ICMP协议进行网络探测

  • -b 后接广播地址，对整个网段进行探测
  • -c ping的次数

arping

待做

ss、netstat

对比维度 netstat ss 面试得分点
数据来源 解析 /proc/net/tcp 等文本文件 直接通过 Netlink 接口与内核通信 ss 避免了大量文本解析和内存拷贝
性能表现 连接数多时极慢（O(n) 遍历） 毫秒级响应，支持内核态过滤 高并发/生产环境排查首选
维护状态 已废弃 (deprecated) iproute2 套件，活跃维护 新系统默认可能不装 net-tools
功能扩展 基础统计 支持 TCP 内部信息（拥塞控制、重传等） -i 参数是高级排查利器
  1. 过滤协议与状态
  • -t / -u / -x：分别过滤出来 TCP / UDP / Unix Socket
  • -a：显示所有状态（LISTEN + ESTAB + TIME-WAIT 等）
  • -l：仅显示 LISTEN 状态（⚠️ 注意：不含 ESTAB）
  • -n：数字形式显示端口/IP，禁止DNS和服务名反解（生产环境必加-n，避免卡顿）
  1. 进程与详细信息
  • -p：显示 PID/Program name（⚠️ 普通用户可能看不到，需 root/sudo）
  • -i：显示 TCP 内部信息（RTT、CWND、SSTHRESH、重传次数等），排查网络质量神器
  • -e：显示 socket 扩展信息（UID、inode 等）
  1. 常见state：
  • LISTEN 监听（只有TCP需要监听）
  • ESTAB 已建立连接
  • UNCONN 未连接（UDP面向无连接，所以UDP的状态都显示UNCONN）
  1. 常用组合：
  • -an 查看本机全部网络连接状态，包括socket套接字程序，TCP，UDP
  • -tuln 显示TCP的监听连接，用于看本机有没有乱开的端口；UDP的UNCONN；缺点是看不到已建立连接的进程
  • -tuan 既能通过-tu过滤掉socket，也能通过-a看到ESTAB状态的连接
    ==- -tulnp没有忽略UDP，查看端口是否被占用，也能知道被占用的端口的进程是谁==

个人理解：TCP面向连接，有多种状态
（LISTEN监听相当于拿起话筒等铃响，ESTAB已建立相当于通话中，TIME-WAIT）
-an就是全部+节省服务名解析
-l是只看LISTEN的状态 经常搭配-t
