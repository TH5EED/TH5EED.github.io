文件传输与下载

发表于2026-08-16|更新于2026-08-16|Linux
|浏览量:

scp

secure copy，基于SSH协议在主机间复制文件

  • -r recursion 递归复制目录
  • -P 指定端口（大写P，SSH端口）
  • -p 保留原文件修改时间、访问时间和权限（小写p）

==scp走SSH隧道，传输加密；但传输大文件不支持断点续传==

wget

非交互式网络下载工具，==支持断点续传、后台下载、递归下载==

选项 作用
-O 指定保存文件名
-c 断点续传
-b 后台下载
-q 静默模式
--limit-rate 限制下载速度

curl

多功能网络请求工具，==支持HTTP/HTTPS/FTP等多种协议==

选项 作用
-O 用远程文件名保存
-o 指定保存文件名
-X 指定HTTP方法（GET/POST/PUT/DELETE等）
-d 发送数据
-H 添加请求头
-L 跟随重定向
-I 只获取响应头
-u 认证用户名:密码
-s 静默模式（不显示进度）

wget vs curl

对比项 wget curl
定位 下载工具 多功能请求工具
协议 HTTP/HTTPS/FTP HTTP/HTTPS/FTP/SCP/SFTP等更多
断点续转 ==原生支持==（-c） 支持（-C -）
后台下载 原生支持（-b） 需配合&
递归下载 ==支持==（爬整站） 不支持
发送请求 不擅长 ==强项==（POST/PUT/DELETE等）

==简单下载用wget，接口调试和复杂请求用curl==
