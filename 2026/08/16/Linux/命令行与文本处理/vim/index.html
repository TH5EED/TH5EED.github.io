三种模式

命令模式

vi/vim进入后的界面，主要用于输入快捷键

移动

  • gg 文件头
  • G 文件尾
  • :n 指定第几行
  • ^ 行首
  • $ 行尾

删除与剪切

  • x 不用进入输入模式，可直接移动光标敲入x删除字母
  • dd 删除行
  • ndd 删除n行
  • dG 从光标所在行删除到文件尾，可达到清空文件作用
  • p 粘贴在光标下一行
  • P 粘贴在光标上一行

撤销

  • u 撤销
  • ctrl+r 反撤销

复制

  • yy
  • nyy

替换

  • r 光标挪到要替换的字符，输入r后跟着输入替换的字符即可
  • 1,10s/old/new/g 替换1-10行的全部old为new
  • %s/old/new/g 替换全部的old为new

s:substitude替换

g:global全部
i:ignore忽略大小写，写在g的左右

查找

  • / 光标所在行向下查找
  • ? 光标所在行向上查找
  • n 下一个
  • N 上一个

输入模式

命令模式输入以下键位进入该模式

  • a 光标所在字符后
  • A 光标所在行尾
  • i 光标所在字符前
  • I 光标所在行首
  • o 向下开一行
  • O 向上开一行

编辑模式

基本

: 冒号进入

  • w 保存编辑不退出，后可跟path/to/file另存一个位置，不加绝对路径将以打开文件时用户所在目录为相对路径
  • q!强制不保存退出
  • wq!强制写入，root用户即使没有权限也能写入

配置

:set 设置

  • nu 显示行数
  • nonu 不显示行数
  • list 显示隐藏字符 tab和回车键
  • nolist 不显示隐藏字符
    可写入~/.vimrc文件中

技巧

导入内容

:r !命令
将命令结果写入文件内

字符串替代

:ab 源字符串 替换字符串
:ab a-z abcdefghjklmn

双开文件

vim -O file file2
ctrl+w H/L切换文件
