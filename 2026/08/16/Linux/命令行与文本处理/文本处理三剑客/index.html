sed

stream editor 流编辑器

基本语法

sed [选项] '脚本' 输入文件

常用选项

-n –quiet 或 –silent 取消默认输出（只打印被显式要求的内容） no print
-e –expression 添加一段脚本（可多个） expression
-f –file 从文件中读取脚本 file
-i –in-place 直接修改原文件（危险！建议先备份） in place
-r 或 -E –regexp-extended 使用扩展正则表达式（ERE） regular

常用命令

p print 打印行 sed -n '2,5p' file 打印2-5行
d delete 删除行 sed '/^#/d' file 删除注释行
s///或s+++ substitute 替换 sed 's/old/new/g' 全局替换
a append 行后追加文本 sed '/pattern/a\new line'
i insert 行前插入文本 sed '/pattern/i\new line'
c change 替换整行 sed '/pattern/c\new line'
y translate 字符一一映射（类似tr） sed 'y/abc/123/'
q quit 退出sed sed '10q' file 打印前10行后退出

awk

数据处理与报表生成器

基本语法

awk [选项] 'pattern { action }' 输入文件

常用选项

选项 英文全称 作用 记忆点
-F field separator 指定输入字段分隔符 Field
-v variable assignment 定义awk变量（在BEGIN前执行） variable
-f file 从脚本文件读取awk程序 file
-V version 显示版本信息 Version

内置变量

变量 含义 示例
$0 整行内容
$1, $2, … 第1、2…个字段
NF Number of Fields（当前行字段数） print NF
NR Number of Records（已读行号，从1开始） print NR
FNR 当前文件的记录号（多文件时独立）
FS Field Separator（输入分隔符，默认为空白） BEGIN{FS=","}
OFS Output Field Separator（输出字段分隔符，默认空格）
RS Record Separator（输入行分隔符，默认换行）
ORS Output Record Separator（输出行分隔符，默认换行）

grep

文件中提取和匹配符合的字符串行
grep <选项> <搜索内容> <文件名>

  • -i 忽略大小写
  • -n 显示行数
  • -v 取反
  • 适用正则表达式

|

命令1 | 命令2
命令1的正确结果作为命令2的操作对象
管道符，文本流操作
所以find不支持|，只能用exec {}
