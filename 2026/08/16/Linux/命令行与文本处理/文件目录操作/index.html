文件目录操作

发表于2026-08-16|更新于2026-08-16|Linux
|浏览量:

引用计数

目录的引用计数指下面的一级子目录个数（包括.和..）

文件的引用计数指该文件的硬链接个数

目录操作命令

ls

  • -i 文件节点号，唯一的；允许同时看两个文件
  • -d 只看当前目录
  • -h 人类可读文件大小
  • –color=[ ] 颜色输出
    always默认
    never从不
    auto自动

cd

    • 返回上一次所在目录
  • .. 上一级目录
    注意相对路径和绝对路径

pwd

mkdir

  • -p 递归创建

rmdir

删除空目录

  • -p 递归删除空目录

rm

  • -r 递归删除目录及其内容
  • -f 强制删除

tree

树形结构显示目录下文件

  • -L [ ] level 显示该目录下多少级子目录

文件操作命令

stat

查看文件详细信息
三个时间戳
新版本有创建时间的时间戳

touch

创建不存在的文件
若存在，修改时间戳
访问时间
更改时间——ls -l——文件内容（内容是属性一部分,更改时间也会变）
改动时间——文件权限

cat

  • -n 显示行数
  • -A 显示特殊符号
  • -b：给非空行编号（比-n更常用，跳过空白行）
  • -s：压缩连续的空行，只显示一行空白（看日志神器）
  • -E：在每行结尾显示 $ 符号（比-A输出更清爽，专门查尾部空格）

more

分屏显示，弥补cat不能看过大文件缺点

  • 空格 向下翻页
  • b 向上翻页
  • 回车 向下翻一行
  • / 搜索字符
  • q 退出

less

逐行显示，more命令选项依旧适用

  • 上下箭头翻行

head

显示文件头几行

  • -n 指定显示文件头几行，默认10
  • -v 指出当前文件名

tail

显示文件末几行，head命令选项依旧使用

  • -f 监听（不能监听系统文件）文件新增内容，删除文件或改名会停止
  • -F 当重建同名文件，继续监听

ln

链接命令
文件名可不一样，但节点号一样
ln [-s] 源文件 目标文件
-s 是软链接
必须采用绝对路径

==文件的block存的是文件的数据
文件的上一级目录的block存的是下面文件的文件名->inode
/的inode号系统直接知道==

硬链接

拥有同一个inode号和block
一个变了，另一个也变
一个没了，另一个照常使用
不能链接目录
不能跨分区（因为inode号会重复）
不明显，不建议使用

软链接

==快捷方式==
inode号不一样
权限l777
一个变了，另一个也变

软链接文件中记录的是目标文件的inode号，所以无论源文件多大，此链接文件还是原来的大小只用来存inode号

文件目录都可操作命令

rm -rf

递归+强制，无论目录文件都这么写

cp

  • -a 完全一致：时间戳，链接文件本身（复制出来的文件同样链接指向最初源文件），权限等，用于备份和迁移
  • -r 递归，用于复制目录

mv

  • -f 强制覆盖
  • -i 覆盖前询问
