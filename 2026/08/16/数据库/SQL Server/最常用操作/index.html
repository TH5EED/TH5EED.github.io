💾 附：SQL Server 备份与恢复命令

SQL Server的备份不是在sqlcmd中执行操作系统命令，而是通过SQL语句完成（备份文件会生成在容器内部）。

🧠 SQL Server vs MySQL 要点速记（避坑指南）

操作 MySQL (mysql客户端) SQL Server (sqlcmd)
语句结束符 分号 ; 必须换行后输入 GO
查看数据库 SHOW DATABASES; SELECT * FROM sys.databases;
自增字段 AUTO_INCREMENT IDENTITY(1,1)
查看表结构 DESC users; EXEC sp_help 'users';
当前时间 CURRENT_TIMESTAMP GETDATE()
备份方式 操作系统命令 mysqldump SQL语句 BACKUP DATABASE

🎯 备份测试验证流程

备份前，务必执行上面的 SELECT CHECKSUM_AGG(BINARY_CHECKSUM(*)) 并记下数值（例如 -123456789）。
备份恢复后，再次执行该命令，如果两次数值完全一致，说明数据完美恢复，备份测试通过！如果容器重启后数据丢了，你就可以用恢复命令找回来。

按照这套流程走，你的SQL Server备份测试准备工作就万无一失了。如果密码或容器名有差异，告诉我，我帮你调整命令。😊
