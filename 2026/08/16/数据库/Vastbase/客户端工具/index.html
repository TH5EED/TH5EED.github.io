vsql

自带，类似sqlplus，mysql

基本功能：

  • 连接数据库
  • 执行SQL语句：支持交互式地键入并执行SQL语句，也可以执行一个文件中指定的SQL语句。
  • 执行元命令：元命令可以帮助管理员查看数据库对象的信息、查询缓存区信息、格式化SQL输出结果，以及连接到新的数据库等。
元命令 全称/含义 作用 示例
\c connect 切换数据库连接。可以连接到另一个数据库或更换用户。 \c mydb myuser
\q quit 退出 vsql 客户端。 \q
\h help 查看SQL命令的帮助。比如想看 CREATE TABLE 的用法。 \h CREATE TABLE
\? help 列出所有元命令的帮助。 \?
\d describe 查看数据库对象（如表、视图、索引）的定义或列表。这是最常用的元命令之一。 \d (列出所有表)
\d mytable (查看表结构)
\l list 列出所有数据库。 \l
\dt list tables 列出所有表。 \dt
\du list users 列出所有数据库角色/用户。 \du
\copy copy 导入/导出数据。与SQL的COPY不同，它操作的是客户端本地的文件。 \copy mytable FROM '/home/user/data.csv' CSV;
\i include 执行一个外部SQL脚本文件。 \i /path/to/script.sql
\timing timing 切换查询耗时显示。开启后，每条SQL执行完都会显示花费的时间。 \timing on
\pset print settings 设置查询结果的输出格式。比如设置边框、对齐方式等。 \pset border 0 (无边框)

高级特性：

  • 设置变量：vsql提供类似于Linux的shell命令的变量特性，可以使用vsql的元命令\set设置一个变量。
  • SQL代换：利用vsql的变量特性，可以将常用的SQL语句设置为变量，以简化操作。
  • 提示符：vsql使用的提示符支持用户自定义。
  • 命令自动补齐：vsql支持使用Tab键进行命令的自动补齐。
  • 客户端操作历史记录：vsql支持客户端操作历史记录，当客户端连接时指定-r参数，此功能被打开。

服务与实例
vb_start/stop/restart（systemctl start mysql)是对于数据库服务的启动关闭管理 vsql连接实例（mysql -u也是这样），创建一个新的进程，此进程为实例 实例才是真正占用CPU，内存的进程，重启进程代表该进程死亡，也就是我们说的数据库挂了数据库服务是在系统中的一段配置 当从客户端登陆进去后，实例主进程会专门派一个子进程接待，退出后该进程被杀死 ==总结==数据库软件装好后，我们启动服务，操作系统就会在后台跑起一个实例（进程）。这个实例守着硬盘上的一堆数据文件。文件里划分了多个数据库（仓库），每个仓库里又分了多个模式（文件夹），文件夹里面才是我们天天打交道的表和列。
