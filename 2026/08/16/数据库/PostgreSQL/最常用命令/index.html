💡 对比 SQL Server：在 sqlcmd 里你只能复制第一行，但在 psql 里，上面的 20 行可以一次全部粘贴成功，因为 psql 会缓存所有输入，直到遇见分号才执行。

✅ 第五步：验证数据完整性（备份前准备）

PostgreSQL 没有 MySQL 的 CHECKSUM TABLE 命令，但我们可以通过行数和整表的 MD5 聚合哈希来替代，记录下这个 MD5 值，恢复后对比。

💾 附：PostgreSQL 备份与恢复命令（在宿主机执行）

PostgreSQL 的备份和 MySQL 类似，是通过操作系统命令 pg_dump 实现的，而不是在 psql 内部执行。

🧠 PostgreSQL vs MySQL vs SQL Server 要点速记（避坑指南）

操作 MySQL SQL Server PostgreSQL (psql)
连接命令 mysql -u root -p sqlcmd -S ... -U ... psql -U postgres
语句结束符 分号 ; 换行后输入 GO 分号 ; (支持多行粘贴)
查看数据库 SHOW DATABASES; SELECT * FROM sys.databases; \l 或 SELECT ...
切换数据库 USE db; USE db; GO \c db
自增字段 AUTO_INCREMENT IDENTITY(1,1) SERIAL 或 GENERATED...
查看表结构 DESC users; EXEC sp_help 'users'; \d users
当前时间 CURRENT_TIMESTAMP GETDATE() CURRENT_TIMESTAMP
备份方式 系统命令 mysqldump SQL 语句 BACKUP DATABASE 系统命令 pg_dump

🎯 备份测试验证流程

  1. 备份前：执行 SELECT MD5(STRING_AGG(...)) 并记录 MD5 值（例如 5d41402abc4b2a76b9719d911017c592）。
  2. 执行备份（使用上面的 pg_dump 命令）。
  3. 模拟损坏/删除（可选）：DROP TABLE users;（测试恢复流程）。
  4. 执行恢复（使用上面的 psql 恢复命令）。
  5. 恢复后：再次执行同样的 MD5 查询。如果两次数值完全一致，说明数据 100% 完整，备份测试通过！

现在尽管放心地把那 20 行数据一次性粘进去吧，psql 不会让你失望的。如果还有问题，随时告诉我！😊
